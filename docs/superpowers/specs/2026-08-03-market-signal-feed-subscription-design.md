`/news`를 **오늘의 상황판**으로 확장한다. 새 탭을 만들지 않는 이유 — CLAUDE.md에 적힌

## 1. 📊 시장 신호

### 데이터 경로 — 시세 단일 지점을 깨지 않는 것이 핵심

`fetchRawMonths`가 반환 시점에 `excludeAbnormal()`을 적용해 해제·직거래를 걷어낸다.
이 함수는 `/trades`·`/trend`·`/rank`·`/briefing` 넷이 공유하는 **시세 정확도의 단일 지점**이라
(CLAUDE.md: "제외 기준을 바꾸려면 여기 한 곳만") 우회로를 뚫으면 그 보증이 깨진다.

**설계**: `excludeAbnormal()`의 반환에 제외된 거래 배열을 **추가**한다.

```js
// before: { trades, cancelled, direct }
// after:  { trades, cancelled, direct, excluded: [...] }
```

시세 경로는 `trades`만 쓰던 대로 쓰므로 **완전 불변**이고, 신호 경로만 `excluded`를 읽는다.
호출부 변경 없이 정보만 늘어난다.

### 지표 4종 (관심 지역, 최근 30일 vs 직전 30일)

| 타일 | 계산 | 필드 | 상태 |
|---|---|---|---|
| 계약 해제 | `excluded` 중 `cdealType==="O"` 건수 | `cdealType` | 파싱됨 |
| 직거래 비중 | `direct / (kept + direct)` | `dealingGbn` | 파싱됨 |
| 법인 순매수 | 법인 매수 − 법인 매도 (건) | `buyerGbn`/`slerGbn` | **파서 추가** |
| 거래량 추이 | 최근 30일 건수, 직전 30일 대비 ▲▼ | — | 계산만 |

참조 사이트의 "단기 계약 비중"은 **전월세 계약기간 지표**라 매매엔 해당이 없어 뺐고,
그 자리를 거래량 추이로 대체했다.

### ⚠️ 자가치유 함정 — 반드시 같이 고칠 것

`lacksDealFlags()`는 `cdealType` 부재로 옛 캐시 행을 미스 처리해 재수집시킨다.
그런데 2026-07-29 이후 재수집된 캐시엔 `cdealType`은 있고 `buyerGbn`은 없다
→ 검사에 안 걸려 **법인 지표만 영영 빈 채로 남는다**.

`lacksDealFlags()`가 `buyerGbn`도 검사하도록 확장해 기존 자가치유 경로를 다시 태운다.
(마이그레이션 없음 — 7/29에 쓴 것과 같은 수법.)

### ⚠️ 착수 전 검증

`buyerGbn`/`slerGbn`이 실거래 응답에 실제로 오는지 **원본 XML 태그를 전수 덤프해 확인**한 뒤
시작한다. 2026-07-29에 `cdealType` 누락을 잡아낸 방법이고, CLAUDE.md의 "가설로 고치기 전에
원본부터" 규칙이다. 2026-08-03 현재 data.go.kr이 `ECONNRESET`으로 응답하지 않아 미검증
상태이므로, 착수 시점에 재시도한다. **필드가 없으면 법인 타일만 빼고 3종으로 간다**
(나머지 3종은 이미 확인된 필드만 쓰므로 영향 없음).

## 2. 🆕 새 거래 피드

`/api/briefing`이 이미 관심 단지 최근 30일 거래를 캐시에서 읽으므로 그 라우트를 확장한다.

⚠️ **`cacheOnly` 성질은 반드시 유지** — 이 라우트는 외부 API를 호출하지 않는 것이 설계다
(cron이 채워둔 `trade_raw_cache`만 읽음). 범위를 넓혀도 이 성질을 깨면 Vercel 함수
타임아웃 위험이 생긴다.

### 탭 2종

- **★단지** (기본) — 현 브리핑과 같은 범위. ★가 적어도 비지 않게 기본으로 둔다.
- **관심지역** — ★가 걸린 `lawd_cd` 전체의 새 거래 중 **내 자금으로 살 수 있는 것만** 상위 N.
  판정은 `calcMaxLoan` 재사용 → 지도·브리핑과 숫자가 어긋날 수 없다(단일 소스 유지).

### 행 형식

참조 사이트의 밀도를 차용하되 우리 강점을 얹는다:

```
[아파트·매매]  안양 동안구 평촌더샵센트럴시티  85㎡ 28층      14.9억
               2일 전 계약 · 직전 대비 +2.1%      [✓ 여유 8천]
```

🆕 판정은 기존 `lib/briefingSeen.js` 재사용(localStorage) — 지도 📰 배지와 공유한다.

## 3. 🏗 청약 레이더

### 승인 대기 — graceful 설계

청약홈 API(`api.odcloud.kr/api/ApplyhomeInfoDetailSvc/v1`)는 2026-08-03 실측 결과
세 가지 인증 방식(encodeURIComponent / raw / `Authorization: Infuser`) 모두
`401 {"code":-4,"msg":"등록되지 않은 인증키 입니다."}` — **서비스별 활용신청 미승인**이다.
(대조군인 실거래가 API는 같은 시각 `ECONNRESET`으로 연결 자체가 끊겨, 실패 양상이 갈린다.)

`kapt.js`가 2026-06-21~25에 쓴 graceful 패턴을 그대로 따른다:
**실패 시 `null` 반환 → 카드를 렌더하지 않음 → 승인되는 순간 재배포 없이 동작**.

사용자가 신청할 것: data.go.kr **"한국부동산원_청약홈 분양정보 조회 서비스"** (자동승인).
승인 확인은 같은 요청을 재호출해 401이 사라지는지로 판정한다.

### 범위와 표시

- **수도권만** — 앱 전체가 수도권(`regions.js` 서울25+경기, `isCapitalAreaNews`)이라 같은 정신.
- **접수 임박순**.
- 우리 강점: **분양가 vs 인근 실거래 중위 대비 %** — 그 지역 중위가를 이미 갖고 있다.

### 저장

`0007_subscription_items.sql` — `news_items`와 같은 패턴(자연키 PK upsert + 기간 프루닝).
수집은 **기존 `/api/cron/news`(06:30 KST)에 합류**한다. Vercel Hobby는 프로젝트당 cron
2개가 한도인데 이미 꽉 차 있어(`refresh` 06:00 + `news` 06:30) 새 cron을 만들 수 없다.

## 시각 — 부분 차용

### 차용

1. **스탯 타일** — 작은 라벨 / 큰 숫자 / 캡션. 시장 신호 카드에 2×2 그리드로.
2. **출처 칩 + 기준시각** — 카드 헤더 우측에 `국토부 신고분` · `06:00 기준`.
   지금은 신선도 표시가 지도 한 곳에만 있다.
3. **하단 범례·면책 각주** — 참조 사이트의 "LTV 40%·30년 원리금균등 가정" 같은 한 줄.
4. **인라인 배지** — 해제/직거래/법인. 지금은 숨기기만 하는 것을 신호로 노출한다.

### ⚠️ 차용하지 않을 것

참조 사이트의 **상승=빨강 / 하락=파랑**(한국 금융 관례, `--rise:#f04452` / `--fall:#3182f6`).
우리는 빨강이 이미 **자금부족**이라 그대로 가져오면 한 색이 두 뜻이 된다.
증감은 **▲▼ 화살표 + 중립 회색/앰버**로 표현한다.

다크 테마도 도입하지 않는다(사용자 선택: 부분 차용).
